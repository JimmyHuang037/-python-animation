## 可以合并的内容

| 共同或衔接内容 | 新PPT证据 | 与既有材料的关系 | 精简方法 |
|---|---|---|---|
| 变量、类型、运算、输入输出 | 第9–23页 | 第10/16讲基础题 | 格式化统一讲一次，其他模块只复用 |
| 分支、循环、range、break/continue | 第24–34页 | 第10/15/16讲程序结构 | 保留执行过程、计数累加与简单嵌套，不单独训练复杂菱形 |
| 字符串、列表、元组、字典 | 第49–61页 | 第06/10/15/16讲容器内容 | 索引、切片、遍历共用一套解释；保留各类型差异 |
| 函数、参数、return、作用域 | 第35–44页 | 第10/15/16讲函数题 | 用已有循环/列表短例封装函数，减少重复铺题 |
| 模块导入与基础库 | 第3–7页、第86页 | 第10讲math/random、第16讲NumPy | import/as/from放在首次使用处；不独立讲大量库背景 |
| NumPy支持绘图 | 第86、88–90页 | 第16讲数组创建和随机数；原大纲数组内容 | 保留array/arange/linspace、shape/dtype、基础索引运算与常见随机函数；绘图复用采样数组 |
| Matplotlib | 第83–90页，第2页明确列编程题 | 原课程范围包含绘图；用户本轮明确保留 | 完整讲数据→绘图→标题坐标图例→show；plot重点，bar/scatter与其他图形识读分层 |

这里的“共同”不表示每份练习都考每个函数；随机数和某些容器方法是既有学校材料的必要补充。

## 差异项建议

- Tkinter：PPT第100–110页及第2页填空范围；建议放校别补充，不进入共同主课。尚未得到用户删除该项的明确决定。
- TXT读写：PPT第63–70页、第2页有字典统计写TXT；用户只明确排除CSV统计，不能称所有文件读写已被用户删除。建议放校别补充。
- Pandas：旧第15讲选择14–21、判断11–14；新PPT未形成Pandas专题。建议不占共同主课，保留约30–40分钟校别基础补充，以直接创建的小表讲Series/DataFrame、索引、排序、均值及统计识读，不安排CSV分析流程。具体时长未冻结。
- lambda、递归：新PPT第45–47页；建议主课不展开，阶乘以循环讲清楚，校别有要求再补。
- 词频与词云、正则与爬虫、CSV统计、独立综合答题模块：按本轮用户明确要求排除。字典基本统计改用成绩等级计数等短例，不保留词频项目。
