## 目的与教学边界

- 面向大一零基础或基础薄弱学生，帮助其达到学校 Python 考试所需能力：读懂短代码、推算输出、补全修改代码、完成范围内的简单程序。
- 交付是动画＋真实 Python 演示的录播课，用户可本人录音、不出镜。其他老师负责一对四上机；录播、暂停练习和上机时间分别计算，不能以看完视频认定已经掌握。
- 按知识与解题任务组织，不硬切期中／期末。学校材料决定内容范围，参考视频用于视觉设计。
- 兼顾笔试和允许运行代码的机试，先推演再运行核对。随知识点保留短例子和必要练习讲评；不另开综合刷题、模拟考试或答题策略模块。
- 初期交付视频、教学代码和所需资料，不自建学生网页 IDE或完整课程平台。

## 当前大纲与模块预算

以[《Python课程大纲.docx》只读副本](../references/imported/current-outline/Python课程大纲.docx)的模块汇总表为准，合计 **510 分钟（8.5 小时）**。来源和 SHA256见[材料清单](../references/imported/manifest.json)。这是制作预算，不是已完成时长。

| 当前模块 | 内容摘要 | 建议时长 |
|---|---|---|
| 基础与输入输出 | 变量、类型、运算、输入转换、格式化输出 | 60 分钟 |
| 条件与分支 | 条件表达式、if/elif/else、边界 | 45 分钟 |
| 循环 | for、while、range、计数累加、break/continue、简单嵌套 | 105 分钟 |
| 列表 | 索引切片、遍历、增删、排序、筛选 | 90 分钟 |
| 字符串、元组、字典 | 常用操作、类型区别、字典查改与遍历 | 65 分钟 |
| 函数与常用模块 | 参数、return、作用域、math/random、导入方法 | 60 分钟 |
| 文件与异常 | open/with、文本读写、编码、JSON 存取、try/except | 40 分钟 |
| Matplotlib、numpy | 折线图、柱状图、散点图、标题坐标、图例、显示 | 45 分钟 |
| 合计 | 模块汇总，不是每课细纲 | **510 分钟** |

用户明确：**每课细纲暂时不改，等用到再说**。附件内细纲和[旧目录建议稿](catalog.md)保持原貌，不据此冻结课数、逐课分钟或统一7+8分钟安排。历史12小时、9.5小时与34课建议不覆盖当前模块表。

范围保留 Matplotlib、文本读写、JSON与异常；排除正则与爬虫、词频与词云、基于文件 CSV的统计分析。Pandas、Tkinter未列入当前模块，不默认增加；排除 CSV统计不等于取消所有文件读写。第10讲中的简单程序设计仍可服务知识讲解。
